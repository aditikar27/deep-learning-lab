Step 1 of 6

Recognize the problem

Read the problem statement and pull out two facts: what the input looks like and what the answer looks like. Those two facts point to one lab.

What is the input?

Rows and columns in a CSV, a CSV of pixel values, image files in folders, images with box labels, or raw text.

What is the output?

A yes/no, one of many classes, a number, boxes around objects, or the next piece of text.

How much data is there?

Hundreds of rows suit a forest. Thousands of images need a CNN or a pretrained model. Tiny image sets need transfer learning.

The eight models

Lab 1Random Forest
What it is

Many decision trees, each trained on a random sample of rows and a random subset of features. The forest predicts by majority vote.

Use when
  • Tabular data with mixed types
  • You want a strong baseline fast
  • No scaling needed, little tuning
Settings that matter
  • n_estimators: number of trees (100 in the lab)
  • max_depth: limits overfitting (5 in the lab)
  • min_samples_leaf, max_features
Watch out
  • Text columns need get_dummies
  • Encode train and test together so columns match
  • Fill missing values before fitting
Lab setting

Features Pclass, Sex, SibSp, Parch, 100 trees, depth 5, random_state=1. Output saved as PassengerId, Survived.

Lab 2MLP on flattened images
What it is

A multi-layer perceptron: fully connected layers with a nonlinearity between them. Each pixel is one input feature, so the image's 2D layout is ignored.

Use when
  • Small, centred, grayscale images (Fashion-MNIST style)
  • Data arrives as pixel columns in a CSV
Settings that matter
  • hidden_layer_sizes=(128, 64)
  • alpha: L2 penalty
  • learning_rate_init, batch_size, max_iter
  • activation: relu or tanh
Watch out
  • Divide pixels by 255 first
  • Hyperparameters were changed one at a time in the lab
What the tuning showed

About 95% validation accuracy at 50 iterations. Raising alpha to 0.001 lowered accuracy, changing the learning rate either way lowered it, batch size 128 dropped it to about 94%, tanh was about 0.1% worse, and (256, 128) was slightly better. Final choice: (128, 64), relu, adam, alpha=1e-4, batch 64, lr 1e-3, max_iter=150.

Lab 3Feedforward neural network (FFNN)
What it is

Stacked Linear → ReLU → Dropout layers written in PyTorch. Training repeats four steps: forward pass, loss, backward(), optimizer step.

Use when
  • Small numeric tables
  • You are asked to build and tune a network yourself
Settings that matter
  • Hidden sizes (4 to 32 tried)
  • Learning rate (0.001 to 0.05 tried)
  • Dropout 0.3, weight decay 1e-4, epochs
Watch out
  • Standardize features, fitting the scaler on train only
  • Zeros in Glucose, BMI and similar columns mean "missing"
  • Load the test CSV from the test file
Lab setting

Two hidden layers (8, 4), lr 0.001, Adam, 300 epochs, full-batch training, 80/20 stratified split. The sweeps over hidden size and learning rate were plotted as accuracy curves.

Lab 4FFNN with BatchNorm and Dropout (regression)
What it is

A deeper FFNN for predicting a number. BatchNorm re-centres each layer's activations so training is stable. Dropout switches off random units to reduce overfitting.

Use when
  • Target is continuous
  • You want the loss to equal the competition metric
Settings that matter
  • Layers (256, 128, 64), SiLU activation
  • Dropout 0.15, AdamW, weight decay 1e-4
  • Cosine learning-rate schedule, patience 12
Techniques used
  • 5-fold cross-validation, test predictions averaged
  • Scaler fit inside each fold
  • Output bias started at the mean target
  • Ratio and volume features added by hand
Watch out

The model output has shape (N, 1). Squeeze it so it matches targets of shape (N,). Call model.eval() before predicting, because BatchNorm and Dropout behave differently in eval mode.

Lab 5CNN trained from scratch
What it is

Convolution layers slide small filters over the image to find edges, then textures, then parts. Pooling halves the width and height. A final dense layer maps features to classes.

Use when
  • Images, and a pretrained model is not allowed or not helpful
  • You want to learn how CNNs work
Settings that matter
  • Image size (160), filters per block (32, 64, ...)
  • Dropout 0.2 to 0.5
  • Augmentation: flip, rotate, zoom, shift
  • Callbacks: EarlyStopping, ReduceLROnPlateau
Watch out
  • Stratified 60/20/20 split so all 120 breeds are in every split
  • Flatten into a Dense layer is huge (26 million parameters in the lab)
What happened in the lab

Loss stayed at 4.79, which is ln(120), so the model was guessing uniformly (test accuracy 1.03%). With 120 classes and about 6,000 training images, a plain two-block CNN is hard to train. The code in step 3 adds BatchNorm and global average pooling to fix this. Details are in the errors section.

Lab 6Transfer learning with ResNet18
What it is

ResNet18 was trained on ImageNet (1.2 million images). Its early layers already detect edges and shapes. You freeze them and train only a new final layer for your classes.

Use when
  • Small image dataset
  • You need good accuracy quickly
Settings that matter
  • Input 224 x 224, ImageNet mean and std
  • Frozen backbone: only 2,052 of 11 million parameters train (4 classes)
  • Adam on model.fc.parameters(), StepLR
Next step
  • Unfreeze layer4 with a lower learning rate (1e-4 or less)
What happened in the lab

Accuracy stayed at 50% and the model had 4 outputs for a 3-class problem. The dataset path pointed one folder too high, so ImageFolder treated the nested folder rps-cv-images as a fourth class and counted every image twice (4,376 instead of 2,188). Training and validation also used the same images. The code in step 3 fixes both.

Lab 7YOLO11 object detection
What it is

A single-stage detector. One pass over the image predicts boxes, classes and confidences. Labels are text files with class x_center y_center width height, all scaled to 0 to 1.

Use when
  • You need locations, not just a label
  • Dataset comes with a data.yaml
Settings that matter
  • Model size: yolo11n (nano) to yolo11x
  • imgsz=640, epochs=30, batch=16
  • freeze=10: keep the first 10 layers fixed
  • patience=10: early stopping
Metrics
  • Precision: of the boxes drawn, how many were right
  • Recall: of the real objects, how many were found
  • mAP50: average precision at IoU 0.5
  • mAP50-95: stricter, averaged over IoU 0.5 to 0.95
What happened in the lab

Test results: precision 0.962, recall 0.307, mAP50 0.448, mAP50-95 0.246. Raccoon reached AP50 0.878. Cat, Dog and Human were weak because the training set had 6, 5 and 25 boxes for them against 247 for raccoon. Detection quality follows the number of examples per class.

Lab 8LSTM text generation
What it is

An LSTM reads characters one at a time and keeps a memory (hidden state). At every step it predicts the next character. The target is the input shifted by one position.

Use when
  • Data is a sequence and order matters
  • The task is to generate, continue or predict the next item
Settings that matter
  • Sequence length 100, stride 5, batch 128
  • Embedding 128, hidden 256
  • Adam lr 2e-3, cosine schedule, gradient clipping 1.0
  • Sampling temperature
Reading the output
  • Low temperature (0.4): safe, repetitive text
  • High temperature (1.2): creative, more mistakes
  • Perplexity = exp(validation loss)
Lab setting

Tiny Shakespeare, 1,115,394 characters, 65 unique characters, 420,289 parameters, 10 epochs, best validation weights restored at the end.

Building blocks you meet in every lab

Train / validation / test splitTrain fits the weights. Validation picks settings. Test is touched once at the end. Use stratify=y for classification.
StandardizationSubtract the mean and divide by the std, using numbers from the training set only. Needed for neural nets, not for forests.
One-hot encodingTurns a text category into 0/1 columns with pd.get_dummies. Do it on train and test together.
Epoch, batch, learning rateAn epoch is one pass over the data. A batch is the slice used per weight update. The learning rate is the step size.
Adam and AdamWOptimizers that adapt the step per weight. AdamW applies weight decay correctly. Adam at 1e-3 is a safe start.
LR schedulersStepLR drops the rate every k epochs. CosineAnnealing glides it down. ReduceLROnPlateau cuts it when validation stalls.
OverfittingTrain score keeps improving while validation gets worse. Fix with dropout, augmentation, weight decay, early stopping, more data.
Dropout and BatchNormDropout randomly zeroes units during training. BatchNorm normalizes layer inputs. Both behave differently in eval() mode.
Softmax and cross-entropySoftmax turns logits into probabilities. Cross-entropy punishes a low probability on the true class. PyTorch's loss includes the softmax.

Lab 8: Character-level LSTM

Train on any plain-text file and generate new text from a seed. For word-level generation, swap characters for words in the vocabulary step.

Change these for a new dataset

  • CORPUS_URL or a local .txt file
  • SEQ_LEN, STRIDE, HIDDEN_DIM (larger = better text, slower)
  • Use temperature 0.5 to 1.0 when generating
Why the target is shifted: for input characters c[0..99] the label is c[1..100]. The loss at each position asks "given everything so far, what comes next?". Reshaping logits to [B*T, V] lets one CrossEntropyLoss call score every position.

Kaggle, step by step

1. Create the notebook

Kaggle, Code, New Notebook. To reuse a lab notebook, choose File, Import Notebook and upload the .ipynb.

2. Join the competition

Open the competition page and press Join, then accept the rules. Without this the data folder stays empty or downloads fail.

3. Add the data

In the notebook press Add Input, search for the competition or dataset, then Add. Run the folder-listing cell below to get the exact path.

4. Turn on the accelerator

Right panel, Session options (or Settings), Accelerator, choose a GPU. Changing it restarts the session, so do it before running anything.

5. Turn on Internet if needed

Required for Lab 6 (ResNet weights), Lab 7 (pip install ultralytics and yolo11n.pt) and Lab 8 (corpus download). Needs a verified phone number.

6. Run and submit

Run all cells. The file submission.csv appears under /kaggle/working. Submit it from the competition's Submit Predictions page or from the notebook's Output tab after Save Version.

Step 6 of 6

Common errors and how to fix them

Find the message you see, read why it happens, then apply the fix. Entries marked From the labs are mistakes that actually appeared in these eight notebooks.

Debug in this order: (1) print shapes and class counts, (2) train on 32 samples and check the loss drops to near 0, (3) only then train on everything. If a tiny set cannot be memorized, the bug is in the data or the code, not in the settings.
